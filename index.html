Proyectos

SalonApp

Aplicación web para la gestión de turnos en salones de belleza y estética. Permite administrar clientes, servicios, agendas y pagos, optimizando la operación del negocio.

  • Tecnologías: React, Node.js, Express, Firebase (Firestore), JWT, Tailwind CSS
  • Arquitectura: Clean Architecture, Repository Pattern, multi-tenant — múltiples sucursales por usuario, cada una con sus propias colecciones (turnos, ventas, clientes, empleados, productos, servicios, promociones, suscripciones)
  • Features:
    • Autenticación con JWT y Google OAuth
    • Gestión de turnos, clientes, servicios, productos y promociones
    • Sección pública de comercios adheridos para tomar turnos online
    • Configuración de agendas por empleado o por cantidad de agendas simultáneas
    • Configuración de horarios de atención por día, semana o mes, con breaks y horarios distintos por día
    • Turnos con o sin seña
    • Envío de mails automáticos de confirmación y cancelación de turnos
    • Exportación de reportes a Excel (clientes, productos y servicios, ventas y turnos)
    • Múltiples modos visuales: modo oscuro, modo barbería
  • Rol: Desarrollo fullstack completo (frontend, backend, arquitectura y despliegue)

FishingSens – Sistema IoT de detección de piques de pesca

Desarrollo de una solución IoT end-to-end para la detección de movimiento en cañas de pescar, con procesamiento en tiempo real y visualización en aplicación móvil.

  • Tecnologías: Arduino (C++), Python (asyncio, WebSockets), Android (Kotlin, Jetpack Compose)
  • Arquitectura: comunicación en tiempo real mediante WebSockets, procesamiento de señal con sensores IMU (MPU6050) y sistema distribuido hardware + servidor + app móvil
  • Features: detección de eventos en tiempo real, comunicación serial y red local, app Android con arquitectura MVVM, procesamiento de datos desde sensores (I2C)
  • Rol: diseño y desarrollo completo de hardware, firmware, backend y aplicación móvil
